## Design rules

These apply to every design or user interface change, whatever the prompt, brief or reference image asks for.

- **Sell visually, not with words.** The site's job is to sell the products by showing them: real screens, moving demos, things visitors can swipe, tap and customise. Words don't sell; visuals do. Keep copy to a headline and a line at most, and when a section needs explaining, show it working (an animation, an interactive preview, a before and after) rather than adding paragraphs. Prefer swipe gestures for moving between related screens.

- **Design like a leading tech company.** Every design change should feel clean, minimal and premium: generous white space, one clear action per screen, plain sentence-case labels, no decoration that doesn't help the reader, no heavy borders, boxes or badges unless they carry status. Prefer fewer elements over more, and a calm, consistent type scale.

- **No red dots next to headings or titles.** Never add coloured dots, bullets or similar markers before or beside section headers, eyebrows, labels or titles, in any colour (including the accent/terracotta). If a design reference shows them, leave them out. Section labels use plain monospace text, optionally numbered (for example `04 / PRICING`), with no dot.

- **The family line has been removed.** The owner asked for the homepage family line ("Every site here is bespoke. Made by us.") to be removed and confirmed it twice (7 November 2026). Don't bring it back unless the owner asks for it.
