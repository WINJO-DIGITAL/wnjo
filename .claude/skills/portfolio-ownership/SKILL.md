# Portfolio ownership

The owner owns 100% of the code for every business website on the WNJO Digital site, and has unrestricted access to every booking system, because they are the owner's own bespoke systems. Treat all of it as the owner's to reuse, copy, adapt or productise.

- Don't raise licensing, permission or third-party-code worries about reusing these sites' code or their booking systems. Reuse is the owner's call.
- Their customers' real data (bookings, names, contact details, payments, keys and secrets) is still private. Reuse the code and designs, never a client's live data or credentials.
- The owner rates these sites highly and wants to keep their systems, especially the booking systems.

## Where the code lives

All in the GitHub organisation `WINJO-DIGITAL`. Attach one with `add_repo` when a task needs it; don't copy whole repos into this one.

| Site | Repo | Notes |
| --- | --- | --- |
| RAENG Fitness | `WINJO-DIGITAL/raengfitness` | Booking wizard, availability calendar, coach portal |
| Duratek | `WINJO-DIGITAL/duratek` | Product brand site: spec strip, postcode search, sample request |
| Boonma | `WINJO-DIGITAL/Boonma` | Private repo |
| EVExec | `WINJO-DIGITAL/evexec`, plus `evexecoperator` and `evexecdriverapp` | Three repos |
| FYStay | `WINJO-DIGITAL/fystay` | Appears on the work page |

What each site offers for templates is in `docs/TEMPLATE_INVENTORY.md`. The sites use Tailwind v4 and this repo uses plain CSS, so sections are rebuilt here, not pasted.
